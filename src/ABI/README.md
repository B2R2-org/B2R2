# B2R2.ABI

### B2R2?

B2R2 is a fully managed binary analysis framework written in F#. It provides a
rich set of algorithms, functions, and tools for reverse engineering, program
analysis, and binary-level inspection.

### B2R2.ABI Package?

`B2R2.ABI` declares ABI-related types and values located under the `B2R2.ABI`
namespace: argument locations, calling conventions, system-call conventions,
and the OS-specific syscall mappings, along with the factories that build a
convention for a given OS and ISA.
